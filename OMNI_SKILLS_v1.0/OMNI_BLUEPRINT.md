# OMNI Skill Set v1.0
### 42 Skills → 8 Engines → 1 Cognitive System

_Full-lifecycle intelligence: idea → brand → design → build → content → SEO → deploy → grow._
_For any project type: websites, web apps, mobile apps, SaaS, tools, e-commerce._

---

## The 8 Engines

| # | Engine | Domain | Activate when... |
|---|--------|--------|-----------------|
| 01 | **THINK** | Ideation, product scoping, brand strategy | Starting any new project, feature, or creative direction |
| 02 | **DESIGN** | UI/UX, design system, responsive, accessibility | Building any interface — web or mobile, any viewport |
| 03 | **MOTION** | Animation, scroll, 3D, micro-interactions | Adding movement, transitions, or WebGL to any UI |
| 04 | **BUILD** | Frontend + Backend, APIs, auth, payments, caching | Writing application code — client or server |
| 05 | **DATA** | Database, schema, queries, optimization, RLS | Designing, querying, or optimizing any data layer |
| 06 | **CONTENT** | SEO, E-E-A-T, content strategy, brand voice | Writing content, optimizing for search, building authority |
| 07 | **SHIP** | Testing, CI/CD, Docker, git hooks, deployment | Shipping code to production safely |
| 08 | **GUARD** | Debugging, governance, safety, evidence-based fixes | Any bug, any failure, any fix that isn't sticking |

## Routing Rules

```
Simple task (CSS fix, rename, typo) → Just do it. No engine needed.
New project or feature → THINK first. Always.
Bug that recurs → GUARD immediately. Code edits blocked until root cause.
Full build → THINK → DESIGN → BUILD + DATA → CONTENT → SHIP
```

## Shared Laws (all engines inherit)

- TypeScript strict. No `any`. Explicit return types.
- Accessibility: WCAG 2.2 AA minimum. 4.5:1 contrast. 44px touch targets.
- Responsive: every UI works at 320px–2560px. No breakpoint is optional.
- Performance: LCP < 2.5s, CLS < 0.1, INP < 100ms.
- Security: validate all inputs. Secrets in env vars only. Never log PII.
- `prefers-reduced-motion`: respected on every animation. No exceptions.
